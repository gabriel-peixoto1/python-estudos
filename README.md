# python-estudos
Quando comecei a estudar Python, fiz diversos exercícios e códigos para treinar novas funções da linguagem. Aqui, você encontrará o caminho desse aprendizado. 

Cada pasta tem o nome da categoria/biblioteca/função estudada e dentro dela tem um arquivo "treino", que usei como base para dominar essa ferramenta. Em alguns casos, também existem listas de exercícios que fiz para me desafiar. 

Atualmente, estou retomando e intensificando o estudo em Python, por isso, planejo incrementar esse repositório com novas ferramentas, exercícios avançados e outros usos interessantes da linguagem.
